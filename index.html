Download

  1. Go to the Releases page.
  2. Download the latest pre-release source package.
  3. Extract the archive to any folder on your computer.
  4. Keep WorkLifeApp.au3 and RunReminder.bat in the same folder.

AutoIt Official Website

This project is built with AutoIt. You need AutoIt3 installed to run or compile the script.

Visit AutoIt Official Website

Compile Tutorial

  1. Install AutoIt3 from the official website above.
  2. Open the WorkLifeApp.au3 script in the SciTE editor that comes with AutoIt.
  3. On the top menu bar, click Tools, then choose Compile Script (shortcut: F7).
  4. Alternatively, right-click the .au3 file in File Explorer and choose Compile script from the context menu.
  5. The compiled .exe file will be created in the same folder as the script.
